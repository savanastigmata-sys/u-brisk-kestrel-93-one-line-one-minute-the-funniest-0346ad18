Write one line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. A judge model pairs the lines and the funniest wins. Free to enter, ten paid places.

This entry's program writes a single one-line excuse to `/output/entry.txt` — no clock, no randomness, no network, so every run writes the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 -P -s main.py
```
